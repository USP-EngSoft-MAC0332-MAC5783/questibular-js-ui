# questibular-js-ui

Interface gráfica do produto do projeto Questibular.

## Stack

- Vue 3
- Vue Router
- Bootstrap 5 + Bootstrap Icons
- Vite

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:5173`.

## Scripts

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Servidor de desenvolvimento |
| `npm test` | Executa os testes automatizados |
| `npm run build` | Executa os testes e, se passarem, gera o build de produção |
| `npm run preview` | Preview do build |

O build falha se algum teste falhar, garantindo a execução da suíte antes de
gerar os arquivos de produção.
